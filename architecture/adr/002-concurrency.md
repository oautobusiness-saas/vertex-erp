# ADR 002 - التعدد والتزامن

## القرار

1. جهاز واحد يعمل بقاعدة بيانات SQLite محلية
2. عند تفعيل تعدد الأجهزة يتحول العمل تلقائياً إلى PostgreSQL على الشبكة المحلية LAN
3. قفل تفاؤلي Optimistic Locking على كل سجل لمنع تعارض تعديلين متزامنين
4. كل حركة بيع أو شراء أو مرتجع أو حركة مخزون تسجل اسم أو رقم الجهاز الذي نفذها
5. أي تعديل بعد الحفظ يسجل اسم المحاسب واسم أو رقم الجهاز في سجل التدقيق
