# ADR 005 - عزل الوحدات (التخصصات)
## القرار
1. يُبنى إطار Plugin مستقل يسمح بإضافة تخصصات جديدة دون تعديل النواة Core
2. قبل أي تخصص حقيقي يُبنى تخصصان وهميان (Dummy) فقط لإثبات أن العزل يعمل فعلياً دون أي تسريب اعتمادية بين الوحدات
3. كل وحدة تتواصل مع النواة فقط عبر العقود المعرفة في مجلد contracts ولا تصل مباشرة إلى بيانات وحدة أخرى
4. حدود كل وحدة وقواعد الاتصال المسموح بها موثقة في مجلد module-boundaries وأي خرق لها يُعتبر خطأ بنائي
5. بعد إثبات العزل بالتخصصين الوهميين تُبنى أربعة تخصصات حقيقية تجارة عامة أحذية ملابس وأقمشة صيدليات بنفس القواعد
