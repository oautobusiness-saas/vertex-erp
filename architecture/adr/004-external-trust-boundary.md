# ADR 004 - حدود الثقة مع الخدمات الخارجية
## القرار
1. Lemon Squeezy يُستخدم حصرياً لمعالجة الدفع وإدارة الترخيص ولا يصل إلى أي بيانات مالية أو محاسبية للعميل
2. Supabase يحمل حداً أدنى من البيانات فقط حالة الترخيص وبيانات الإحالات ولا يخزن أي حركة محاسبية أو بيانات عملاء حقيقية
3. قاعدة بيانات العميل المحاسبية الكاملة تبقى محلية على جهاز أو شبكة العميل فقط ولا تُرسل لأي خدمة خارجية بأي شكل
4. أي اتصال بخدمة خارجية يُسجل في سجل التدقيق باسم الخدمة والغرض والتوقيت
5. في حال انقطاع الاتصال بالخدمات الخارجية يستمر البرنامج بالعمل الكامل محلياً دون أي تعطل
