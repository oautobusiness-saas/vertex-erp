# ADR 006 - وضع التدريب (Training Mode)

## القرار
1. عزل كامل على مستوى قاعدة البيانات عبر ملف منفصل تماماً بنفس هيكل الجداول الحقيقية، وليس مجرد عمود فلترة داخل نفس الجداول
2. شريط لوني واضح وثابت أعلى الواجهة طوال فترة العمل في وضع التدريب، وليس رسالة تظهر مرة واحدة فقط
3. عند حفظ أي قيد أو فاتورة من أي نوع تظهر رسالة تأكيد نصها أن هذه بيانات تدريبية ولن تحتسب في حسابات الشركة الحقيقية مع زر أوافق إجباري قبل إتمام الحفظ
4. ترقيم فواتير وقيود منفصل تماماً عن الترقيم الحقيقي لمنع أي التباس عند المراجعة لاحقاً
5. صلاحية تصفير بيانات التدريب بالكامل متاحة للمالك فقط، وهذا مسموح هنا خلافاً لقاعدة عدم الحذف الفعلي لأن البيانات تدريبية وليست بيانات عملاء حقيقيين
6. نفس كود ومنطق البرنامج الحقيقي بالكامل محرك القيد وحساب المخزون والتقارير، ويختلف فقط الاتصال بقاعدة البيانات حسب الوضع المفعل
7. وضع التدريب مرتبط بجلسة دخول كل مستخدم على حدة، فتفعيله لمستخدم لا يؤثر على مستخدمين آخرين يعملون في نفس الوقت على أجهزة أخرى
