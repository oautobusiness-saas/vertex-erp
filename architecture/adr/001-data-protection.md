# ADR 001 - خطة حماية البيانات

## القرار

1. قاعدة بيانات العملاء الحقيقية لا تُرفع لهذا الريبو (Public) أبداً - .gitignore يمنع ملفات db و mdf وأي ملف إعدادات فيه مفاتيح تشفير
2. الحذف داخل البرنامج Soft Delete فقط IsDeleted true - لا حذف فعلي من القرص
3. نسخ احتياطي تلقائي مستمر لكل حدث + نسخة محلية backup.db + رفع الفروقات فقط لمكان مشفر خارج الجهاز
4. علامة git tag بعد كل مرحلة بناء ناجحة للرجوع الفوري عند أي خطأ
5. فرع main محمي من الحذف والرفع القسري من إعدادات GitHub
6. أي تعديل على حركة محفوظة يتطلب باسوورد المالك ويُسجَّل باسم المحاسب والجهاز
