# ADR 003 - استراتيجية محرك القيد المزدوج

## القرار

1. يُبنى منطق القيد المزدوج أولاً بلغة Python كنموذج مرجعي مستقل لاختبار صحة المعادلة المحاسبية قبل أي كتابة بلغة C#
2. تُكتب اختبارات JSON تغطي حالات القيد الأساسية مدخلات ومخرجات متوقعة وتُستخدم كمرجع مطابقة عند إعادة البناء بلغة C#
3. لا يبدأ تنفيذ محرك القيد بلغة C# إلا بعد اجتياز جميع اختبارات نموذج Python بنجاح كامل
4. أي تعديل لاحق على منطق القيد يجب أن يمر أولاً على نموذج Python واختبارات JSON قبل تطبيقه في C#
5. الهدف عزل منطق المحاسبة الحساس عن تعقيد الواجهة والتأكد من صحته رياضياً قبل الاستثمار في كود الإنتاج
